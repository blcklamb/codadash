# codadash (코다대시) 기획서

문서 버전: 1.0 · 작성일: 2026-09-10 · 작업 경로: `/Users/jeong/dev/keybit`

## 서비스 정의

codadash(코다대시)는 개발자가 프로그래밍 언어의 코드를 직접 입력하며 손을 풀고, 자신의 기록과 친구의 실력에 도전하는 타자 게임이다. 자동완성과 AI 도구로 직접 입력하는 시간이 줄어든 개발자에게 짧고 즐거운 워밍업을 제공한다.

핵심 문구: **자동완성은 잠깐 끄고, 손맛은 켜세요.**
영문 문구: **Less autocomplete. More fingerwork.**

## 대상과 목표

- 업무를 시작하기 전 1~2분 손을 풀고 싶은 개발자.
- 영문·기호·코드 입력에 더 익숙해지고 싶은 입문 개발자.
- 짧은 개인 기록 경쟁과 지인 대전을 즐기는 개발자.

사용자에게 제공할 동기는 개인 최고 기록, 일일 도전, 연속 연습일, 친구와의 승부 및 재대결이다. 실력 향상을 보장하거나 개발 생산성과 타자 속도를 동일시하지 않는다.

## 첫 출시

지원 언어는 JavaScript, TypeScript, Java, Rust, Go, Python, C, C++, C#, Swift, Bash다. 한국어와 영어 UI를 제공한다. 데스크톱·노트북 키보드로 플레이하며 모바일에서는 소개·로그인·기록을 확인한다.

1. 속도 측정: 제한 시간 동안 코드 블록을 완성한다.
2. 일일 연습: 같은 날짜·언어에서 동일한 도전을 플레이한다.
3. 1대1 대전: 초대 코드로 참여해 떨어지는 코드를 제거하고 연속 성공으로 상대에게 추가 코드를 보낸다.
4. 비회원 즉시 플레이와 선택적 GitHub 로그인.
5. 개인 기록, 연습 달력, 연속 연습일, 소리·효과 설정.

공개 순위, 자동 매칭, 랭크, 시즌, 상점, 채팅, 관전, 친구 목록, 결제, 사용자 코드 업로드와 실행은 후속 범위다.

## 핵심 흐름

### 혼자 손 풀기

언어 → 난이도·시간 → 3초 카운트다운 → 코드 입력 → 완료 수·CPM·정확도 → 최고 기록 비교 → 같은 설정 재도전.

### 매일 돌아오기

오늘의 도전 → 언어 선택 → 60초 연습 → 최소 한 블록 완료 → 달력 체크·연속 연습일 갱신 → 재도전 또는 다음날 방문.

### 친구와 경쟁하기

방 생성 → 코드·링크 복사 → 상대 입장 → 두 사람 준비 → 120초 이내 산성비 → 승패 이유·양측 통계 → 재대결 동의.

## 화면 설계

- 왼쪽 내비게이션: 속도 측정, 일일 연습, 1대1 대전, 내 기록, 설정.
- 상단: 현재 위치, 한국어·영어 전환, GitHub 로그인.
- 개인 연습 시작 화면: 모드 카드, 11개 언어, 코드 미리보기, 시간·난이도, 시작.
- 연습 플레이: 남은 시간·완료 수·CPM·정확도, 코드와 커서, 입력 안내.
- 결과: 실제 측정 지표, 새 기록, 구간별 속도, 오타 문자, 재도전.
- 일일 연습: 날짜·다음 갱신 시간·연속일, 언어별 도전, 최근 30일 달력.
- 대기실: 코드, 초대 링크, 두 참가자, 방장 설정, 준비.
- 대전: 큰 내 보드, 작은 상대 보드, 체력·시간·공격 예고, 입력창.
- 내 기록: 언어·모드 필터, 최근 세션, 계정과 기기 비회원 기록 구분.
- 설정: UI 언어·효과음·도트 효과·흔들림·모션 감소·로그인.

## 디자인 방향

차분한 개발 도구 화면에 작은 도트 아케이드의 손맛을 더한다. 큰 마케팅 화면보다 즉시 연습할 수 있는 작업 화면을 우선한다.

- 배경 `#0B0F14`, 패널 `#141B24`, 본문 `#E6EDF3`.
- 내 플레이·성공은 민트 `#5EEAD4`, 상대·공격은 보라 `#A78BFA`.
- 경고는 노랑 `#FBBF24`, 오류·피해는 빨강 `#FB7185`.
- 코드: JetBrains Mono, 합자 끔. UI: Noto Sans KR.
- 도트는 로고·작은 장식·콤보·파티클에만 사용하고 코드의 읽기 편함을 유지한다.
- 입력 반응은 즉시, 승패·피해 연출은 서버 확정 후 표현한다.
- 효과음·흔들림은 기본 꺼짐. 모션 감소를 지원한다.

위트는 시작·결과 문구에 쓰고 연결·저장 오류는 명확하게 안내한다. 사용자에게 실패를 과장하거나 출석 단절로 죄책감을 주지 않는다.

## 검증할 제품 가설

출시 후 첫 4주에 연습 완료율 80%, 같은 방문 재도전율 30%, 두 사람 입장 후 경기 시작률 90%, 재대결 성사율 25%, 가입자의 첫 플레이 후 7일 이내 재방문율 20%를 목표 가설로 확인한다. 실측 전 수치를 성과로 표시하지 않는다.

## 기술·비용 방향

React/Vite 정적 프런트, Express/Socket.IO 단일 게임 서버, Supabase GitHub 로그인·PostgreSQL 저장을 사용한다. Cloudflare Pages와 Render, Supabase로 배포한다. 초기 월 5만 원 안팎을 목표로 하며 도메인·환율·세금·초과 사용량은 별도다.

자세한 판정 규칙·API·검증 조건은 REQUIREMENTS.md, 실제 운영 설정과 외부 검증 제한은 OPERATIONS.md 및 VALIDATION.md를 따른다.
