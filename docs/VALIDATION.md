# keybit 검증 상태

2026-09-10. 실제 수행한 결과만 기재한다.

## 로컬 검증 완료

- TypeScript 검사와 프런트·서버 배포용 빌드 통과.
- Vitest 31개 통과: 타자·콘텐츠·날짜·대전 규칙, 실제 서버 소유권/재접속/중복 입력, PostgreSQL 스키마·RLS, 장기 최고 기록 보존, 지연 대전.
- 11개 언어 550개 코드 조각의 수량·중복·ASCII·길이·줄 수 검증.
- Chromium·Firefox·WebKit에서 브라우저 시나리오 15개 확인. 연습 실제 타이머, 기록 유지, 초대 대전·재접속·기권, 일일 화면, 언어/설정, 모바일 안내, 1280×720 배치, 입력 반응, 저장 차단 시 실패 표시를 포함한다.
- 전체 브라우저 실행에서 14개 통과, Firefox 저장 차단 시나리오 1개는 개발 화면 재로딩이 발생한 실행에서 실패했다. 소스 변경 없이 해당 시나리오를 다시 실행해 통과했다. 단일 실행에서 15개 전부 통과한 것으로 기록하지 않는다.
- 입력 렌더링 검증은 키 이벤트 다음 프레임까지 p95 50ms 미만을 확인한다. 전체 웹 성능/실사용자 측정의 대체 지표는 아니다.
- 100ms 왕복 지연 프록시를 사용한 실제 대전에서 입력 확인과 동일 기초 코드, 상보적 최종 승패 및 상대 수치 일치를 확인했다.
- PostgreSQL은 PGlite의 실제 PostgreSQL 실행기로 마이그레이션과 RLS를 검증했다. Docker 기반 로컬 Supabase 전체 스택은 실행하지 않았다.

## Supabase 연결 진행 상태

- 사용자 제공 프로젝트 URL과 로컬 Publishable/Secret 키를 설정했다. 키는 Git 제외 파일에만 보관한다.
- 인증 API HTTP 200, 서버·프런트 프로젝트 일치, 공개/비밀 키 구분을 확인했다.
- 최초 HEAD 요청은 없는 테이블 오류를 올바르게 판정하지 못했다. 연결 점검을 본문이 있는 GET 요청으로 수정했고, 테이블/뷰가 아직 없는 상태임을 확인했다.
- 사용자가 초기 SQL을 적용한 뒤 테이블 3개와 뷰 2개의 실제 조회가 성공했다.
- 일회성 계정 2개로 Supabase 사용자 토큰 발급, 실제 30초 연습, 게임 서버의 결과 저장, 최고 기록 조회를 확인했다.
- 계정별 API 격리, RLS 본인 조회 허용 및 타인 조회 차단, 브라우저 점수 위조 거부(42501)를 실제 프로젝트에서 검증했다. 테스트 계정 2개와 해당 기록 및 세션 정리도 확인했다. 원본 결과는 output/supabase-smoke-report.json에 있다. 이메일/비밀번호로 발급한 일회성 계정 토큰을 사용했으므로 GitHub OAuth 검증과 구분한다.
- Supabase 연결 후 Chromium의 실제 연습, 초대 대전, 설정 시나리오 3개를 다시 실행해 모두 통과했다.
- 실제 설정을 반영한 배포 빌드 통과. 프런트 배포 파일에 Publishable 키가 포함되고 Secret 키가 포함되지 않았음을 확인했다.
- GitHub 공급자 활성화와 연결 점검 전체 통과를 확인했다. 사용자가 실제 GitHub 로그인, keybit 복귀, 30초 연습 완료를 보고했다. Supabase에서 GitHub 공급자 계정의 최근 로그인, JavaScript 30초 기록, 정상 종료 세션, 최고 기록 반영을 읽기 전용으로 확인했다. 원본 결과는 Git 제외 파일 output/github-login-report.json에 있다. 브라우저 자동 접근은 관리자 정책 확인 오류로 차단되어 사용자 조작과 DB 확인을 결합해 검증했다.

## 외부 환경에서 남은 확인

- 동일한 실제 GitHub 계정으로 독립된 두 기기에서 로그인해 기록을 조회하는 확인. 현재는 실제 로그인과 서버 저장, 일회성 계정의 조회 및 접근 제어까지 확인했다.
- Render·Cloudflare Pages 공개 배포와 허용 출처 확인.
- 실제 유료 인스턴스 부하·지역 간 네트워크 지연.
- 실제 Safari·Microsoft Edge 앱 확인. 자동 검증은 WebKit·Chromium 엔진을 사용한다.

구현과 검증 범위를 구분하며, 외부 서비스에서 아직 확인하지 않은 항목을 완료로 표시하지 않는다.
